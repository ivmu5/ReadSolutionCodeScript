# C# Project Export

Небольшая CLI-утилита для объединения всех `.cs`-файлов проекта в один текстовый файл.

Полезно для передачи исходников в LLM, code review, анализа архитектуры и создания текстового снимка проекта.

## Возможности

* Рекурсивный поиск `.cs`-файлов
* Исключение `bin`, `obj`, `.git`, `.vs`
* Относительные пути вместо абсолютных
* UTF-8 без BOM
* Прогресс экспорта и статистика
* Продолжение работы при ошибке чтения отдельного файла
* Поддержка аргумента командной строки и интерактивного ввода

## Использование

Через аргумент:

```powershell
ProjectExporter.exe "D:\Projects\MyProject"
```

Или просто запустите программу:

```powershell
ProjectExporter.exe
```

После этого введите путь:

```text
Enter project directory: D:\Projects\MyProject
```

Результат сохраняется на рабочий стол:

```text
MyProject_260916_1135.txt
```

<details>
<summary><strong>Формат результата</strong></summary>

Каждый файл отделяется заголовком с относительным путём:

```text
====================================================
Services\DatabaseService.cs
====================================================
using System;

public class DatabaseService
{
    // ...
}
```

Абсолютные пути к проекту в экспортируемый файл не записываются.

</details>

<details>
<summary><strong>Исключаемые директории</strong></summary>

Автоматически игнорируются:

```text
bin
obj
.git
.vs
```

Проверка не зависит от регистра.

</details>

<details>
<summary><strong>Статистика</strong></summary>

После завершения программа показывает:

* количество найденных файлов;
* количество исключённых файлов;
* количество успешно обработанных файлов;
* количество ошибок;
* общее количество строк;
* количество непустых и пустых строк;
* среднее количество строк на файл;
* размер исходников;
* размер итогового файла;
* время выполнения.

</details>

<details>
<summary><strong>Обработка ошибок</strong></summary>

Если отдельный файл невозможно прочитать, экспорт остальных файлов продолжается.

Ошибка записывается в итоговый файл и выводится в консоль.

Коды завершения:

```text
0 — экспорт завершён успешно
1 — критическая ошибка
2 — экспорт завершён, но некоторые файлы не удалось обработать
```

</details>

<details>
<summary><strong>Поддерживаемые файлы</strong></summary>

Текущая версия экспортирует только:

```text
*.cs
```

Не экспортируются `.csproj`, `.sln`, `.xaml`, `.json`, `.xml`, `.md` и другие файлы проекта.

</details>

## Требования

* .NET
* C# 12+
